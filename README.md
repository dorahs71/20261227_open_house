# Discover Your Talent — Premium & BID Toastmasters Open House

12/27 開放參觀日活動網頁，內建「職場天賦原型」心理測驗。

## 活動資訊

- **主辦**：Premium & BID Toastmasters
- **活動**：12/27 Open House 工作坊
- **帶領者**：Edward Chen, DTM（資深職業教練）

## 功能

- **首頁**：活動介紹與行動呼籲（做測驗 / 報名 Accupass）
- **心理測驗**：6 題直覺排序，1 分鐘測出職場天賦原型
- **結果頁**：揭曉四大原型之一，並引導報名工作坊

### 四大天賦原型

| 原型 | 代表色 |
|------|--------|
| 🧭 策略領航員 | 藍 |
| 🧡 暖心賦能者 | 橘 |
| 📖 魅力說書人 | 紫 |
| 🚀 遠見影響家 | 綠 |

## 技術

純前端，單一 HTML 檔案，無需建置步驟：

- Vanilla HTML / CSS / JavaScript
- Google Fonts（Plus Jakarta Sans、Noto Sans TC）
- 無外部框架、無後端依賴

## 使用方式

直接用瀏覽器開啟 `index.html`，或部署至任何靜態網站服務（GitHub Pages、Netlify 等）。

```bash
open index.html
```
